# Church Book Stall — Vite + React

Local single-page app for managing book sales for a church bookstall.

Features:
- Sales Counter with search, cart, quantity controls
- Payment page with UPI deep link and "Mark As Paid" which saves bill to LocalStorage
- Sales History with search and date filter
- Book Management (Add / Edit / Delete)
- LocalStorage persistence
- Responsive UI using Bootstrap

Run locally:

```bash
npm install
npm run dev
```

Open http://localhost:5173 (or the address Vite prints).
